# Inbox

Bandeja de entrada. Todo lo nuevo entra aquí sin preocuparse por organización.

## Reglas

1. Crea archivos con fecha: `YYYY-MM-DD-tema.md`.
2. Frontmatter mínimo (puedes copiar de `00-meta/plantillas/nota-general.md`).
3. Los `[[wikilinks]]` se toleran aquí como borrador.
4. Procesa cada semana: mueve a su carpeta final, completa frontmatter, enlaza en `_index.md`.

## Ejemplo

```markdown
---
title: Idea fuente regulable
area: electronica
tags: [electronica, estado/borrador]
created: 2026-09-07
updated: 2026-09-07
related: []
---

# Idea fuente regulable
...
```
