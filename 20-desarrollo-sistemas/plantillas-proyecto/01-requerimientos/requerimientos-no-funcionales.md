# Requerimientos no funcionales

Describen cómo debe comportarse el sistema: rendimiento, seguridad, usabilidad, disponibilidad y restricciones.

| ID | Categoría | Requerimiento | Métrica |
|----|-----------|---------------|---------|
| RNF-01 | Rendimiento | | Ej: respuesta < 2 s |
| RNF-02 | Seguridad | | |
| RNF-03 | Usabilidad | | |
| RNF-04 | Disponibilidad | | Ej: 99.5% |
| RNF-05 | Compatibilidad | | |
| RNF-06 | Restricción | | Ej: lenguaje, SO, norma legal |
